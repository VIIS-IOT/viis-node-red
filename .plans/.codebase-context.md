# Codebase Context Cache

> Last updated: 2026-05-28 14:00
> Stale sections: none

## Tech Stack
- Language: TypeScript (Node.js)
- Framework: Node-RED custom nodes
- Database: PostgreSQL (TypeORM), MySQL (local)
- MQTT: ThingsBoard + EMQX (dual broker)
- Modbus: TCP/RTU via custom ModbusClientCore
- Testing: Jest
- Package manager: npm
- Build: tsc + tsc-alias

## Project Structure
```
viis-node-red/
├── src/
│   ├── core/                    ← Shared singletons (ClientRegistry, ModbusClient, MqttClient)
│   ├── modules/                 ← All custom nodes (32+ modules)
│   │   ├── viis-schedule-executor/        ← V1 monolithic (3500 lines)
│   │   ├── schedule-executor-v2/          ← V2 composable (3 nodes)
│   │   │   ├── common/                    ← Shared types + utils
│   │   │   ├── viis-schedule-trigger-v2/  ← Timing check
│   │   │   ├── viis-schedule-logic-v2/    ← Mode/safety/mapping
│   │   │   └── viis-schedule-executor-v2/ ← Execution + notifications
│   │   ├── viis-modbus-flex/              ← Modbus reader
│   │   ├── viis-rpc-control/              ← RPC + Modbus write
│   │   ├── viis-mqtt-client/              ← MQTT pub/sub
│   │   └── ... (28+ other modules)
│   ├── orm/                     ← TypeORM entities + datasource
│   ├── services/                ← Shared services (SyncScheduleService)
│   └── ultils/                  ← GlobalContextHelper
├── tests/
├── dist/                        ← Compiled output
├── package.json                 ← 33 registered node types
└── tsconfig.json
```
